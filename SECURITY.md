# Security Policy

## Supported Versions

Security updates are applied to the latest `main` branch and the current production deployments of **sYnX Web** (`synx.christran.io`) and **sYnX Mobile**.

| Surface | Supported Version |
| :--- | :--- |
| Web & Cloudflare Worker API | Latest `main` (`5.x`) |
| Mobile (Android / iOS) | Latest release (`3.x`) |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them privately using one of the following channels:

1. **GitHub Private Vulnerability Reporting**: Open the repository's **Security** tab on GitHub and click **Report a vulnerability** (`https://github.com/sYnVerse/sYnX/security/advisories/new`).
2. **Direct Contact**: Reach out to the maintainer via [christran.io](https://christran.io).

### What to Include

- A clear description of the issue and its potential impact.
- Step-by-step instructions or a minimal proof-of-concept to reproduce the vulnerability.
- Any affected routes, endpoints (`/api/v1/*`), or mobile screens.

We will acknowledge receipt within 72 hours and work with you to validate, remediate, and disclose the issue responsibly.
